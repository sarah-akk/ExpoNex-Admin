🎪 Exhibition Management System
A comprehensive platform designed to streamline the entire exhibition process, catering to multiple user roles:

🔹 Admins – Create and manage exhibitions, monitor performance, and oversee users.
🔹 Companies – Reserve sections, showcase products, and participate in auctions.
🔹 End Users – Attend exhibitions, explore showcased products, and provide feedback.

🚀 Key Features
✅ Intuitive Dashboard – A dynamic interface offering real-time exhibition analytics.
✅ Exhibition Creation & Management – Admins can enter detailed info, map locations, design booth layouts, and customize tickets.
✅ Seamless Event Control – Track exhibition status, manage attendees, and access analytics per event.
✅ User & Product Management – Curate exhibitor content with moderation tools and browsing features.
✅ Auction System – Companies can bid for prime exhibition sections and manage product listings with ease.
✅ Performance Analytics – Companies can track engagement, visitor trends, and section performance.

🛠️ Tech Stack
Frontend: React.js
